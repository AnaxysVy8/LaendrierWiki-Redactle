# Fragenecke

1. Was ist Redactle?
Redactle ist ein Browserspiel, bei welchem man einen Wikipedia-Artikel erraten muss, indem man Wörter rät und dabei ihn bisschen für bisschen und Wort-für-Wort aufdeckt.

2. Wie funktioniert Redactle?
Man errät Wörter, wie "bekannt" oder "Automobil", um herauszufinden, was der Titel - oder worüber der Artikel handelt - ist. Dabei bleiben aber Grundwörter, wie Artikel, "kann", "auf", "und" und "oder", sowie weitere, jedoch aufgedeckt.

3. Wie spielt man im Mehrspieler?
Du bist automatisch Host. Teile einfach den oben stehenden Link mit einem Mitspieler, warte einen Moment und voilà.
